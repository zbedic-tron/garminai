# GarminAI

Independent, free-to-use running analytics project currently under development.

This repository initially hosts a static information website, a contact page, and a privacy policy for the **website only**. Public Garmin account integration has **not launched**.

## Publishing

Upload `index.html`, `privacy.html`, `contact.html` and `style.css` to the repository root. In **Settings → Pages**, set **Source: Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.

Expected site: https://zbedic-tron.github.io/garminai/

**Security:** Never commit API credentials, access tokens, passwords, personal activity exports, or private fitness data.

GarminAI is not affiliated with, endorsed by, or sponsored by Garmin Ltd. or its affiliates.
